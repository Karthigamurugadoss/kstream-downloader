features

Everything you need to download media

No bloat, no ads, no tracking. Just a clean tool that does its job.

🎬

Video Download

Download in Best, 1080p, 720p, 480p, or 360p. FFmpeg automatically merges audio and video streams.

🎵

Audio Extraction

Extract audio from any video as MP3 at 320, 192, or 128 kbps. Studio to standard quality.

📦

Bulk Download + ZIP

Paste multiple URLs, download concurrently with 3x parallelism, and get a single ZIP file.

📝

Transcript Grabber

Download subtitles and captions in VTT format. Supports English, Tamil, Hindi, Telugu, Malayalam.

how it works

Up and running in 2 minutes

Clone, install, run. No complicated setup.

01

Clone the repo

git clone the repository and cd into the project directory.

02

Install dependencies

pip install -r requirements.txt — that's Flask, yt-dlp, and a few helpers.

03

Run the app

python app.py — open localhost:5000 and start downloading.
